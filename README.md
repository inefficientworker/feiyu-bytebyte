# 肥鱼拜拜

B 站评论区油猴脚本：[feiyu-byebye.user.js](./feiyu-byebye.user.js)。在浏览器本地用 [is-dafeiyu](https://huggingface.co/inefficentworker/is-dafeiyu) 识别头像，结合昵称、账号等级评分；达到阈值后只显示头像、名字，以及展开和白名单按钮。

## 安装

在安装好 Tampermonkey、ScriptCat 等脚本管理器后，直接打开仓库 `main` 分支的脚本链接即可安装并支持后续自动更新：

<https://raw.githubusercontent.com/inefficientworker/feiyu-bytebyte/main/feiyu-byebye.user.js>

安装后刷新网页即可生效。

## 调整评分

所有预置参数位于脚本顶部。分数越高越容易折叠，默认 `SCORE_THRESHOLD = 80`，不是百分比，允许超过 100。

| 项目 | 默认计分 |
| --- | --- |
| 头像 | 模型概率 × 70 |
| 昵称含“大肥鱼 / 鲸鱼娘” | +30 |
| 昵称含“肥鱼 / DeepSeek” | +25 |
| 昵称含“小鱼” | +20 |
| 昵称含“鲸” | +15 |
| 昵称含“鱼” | +10 |
| 上述昵称同时含“打工 / 运营 / 营业 / 加班 / 摸鱼 / 投喂” | 额外 +5 |
| LV0–3 | +15（降低可信度，因此增加可疑分） |
| 等级未知 / LV4–6 | +0 |

昵称基础项取最高分，不叠加；英文不区分大小写，用 NFKC 兼容全角字符，仅转换相关繁体字 `魚鯨孃運營`。只读取评论作者的昵称，不扫描评论正文或被 @ 的人。

除总分达标外，头像必须达到 `MIN_AVATAR_PROBABILITY = 0.42624813318252563` 的模型门槛。因此低等级或相似昵称本身不会折叠评论。头像满分也不可能达标的账号直接跳过推理。

单条评论**点赞超过 5 时不折叠**，优先于评分，主评论和楼中楼分别判断；5 赞仍按原规则处理。顶部 `LIKE_EXEMPTION_THRESHOLD = 5` 可调整这个界限。页面点赞数更新后会自动重新判断，超过界限的已折叠评论会恢复；点赞数尚未读取到时先保持显示。

例如：`贪吃的小鱼儿` 的头像概率约 0.9976、LV2，得分为 `69.8 + 20 + 15 = 104.8`；`小鱼不加班_Channel` 再加角色词分，约 109.7 分。调整 `SCORE_THRESHOLD`、`AVATAR_WEIGHT`、`NAME_RULES`、`LOW_LEVEL_SCORE` 后刷新即可生效，已缓存的头像概率会按新权重重新计分。

## 展开与白名单

- 点击“展开评论”恢复原评论；再次点击可收起。展开后可查看头像、昵称和等级的评分明细。
- 只折叠作者自己的评论，主评论下其他用户的回复仍保留。
- “加入白名单”按 UID 保存，立即恢复该账号当前页面的所有评论，并同步其他已打开的 B 站页。昵称变更不影响白名单。
- 脚本菜单提供运行状态、失败重试、白名单管理和缓存清理。白名单管理每行一个 UID，删除一行即移除。
- 内置保护 `3747571004608077` 和 `518791169`，优先于所有评分。前者在实际头像测试中达到 99.89%，会被仅靠头像和昵称的规则误判；后者头像为 2.98%，未过门槛。根据用户指定真人身份，将两者都保护。

## 模型与缓存

固定 Hugging Face revision `db483a6f487008e849a91617e9eb491083c180ac` 的 `artifacts/mobilenetv3_user_20261123/model_browser_fp16.onnx`，大小 8,439,096 字节。SHA-256：

```text
52a25ed2102b84cd552241ba5b29e4c53708fe256cead50a25deaea039e5588a
```

先尝试 `hf-mirror.com`，失败、超时或校验不符后尝试 `huggingface.co`。使用脚本管理器的跨域请求，避免页面 CORS 限制。模型在 GM 存储中缓存，跨 B 站子域复用；首次下载和每次从缓存加载都验证大小及 SHA-256，损坏缓存删除后重下。两源均失败或推理失败时保持评论显示，可从菜单重试。

头像使用原始图片 URL，在浏览器本地推理，不上传头像或评论。成功结果按模型哈希和头像 URL 缓存 7 天、最多 2000 项；修改昵称和等级会重新评分，更换头像会重新识别。相同头像请求合并，推理串行。ONNX Runtime Web 1.20.1 通过固定版本 CDN 加载，WASM 单线程运行。

评分是启发式筛选，不能据此证明账号由 AI 运营，也无法保证所有未见过的真人账号零误报；指定的两个真人账号由 UID 白名单明确保证不折叠。
